## 🎯 Key Concepts

### What is Network Analysis?
- **Definition**: Capturing, monitoring, and analyzing network traffic to identify security threats
- **Primary Tools**: Wireshark, TCPDump for packet capture and analysis (PCAPs)
- **Core Skills**: Protocol understanding, suspicious activity detection, traffic pattern analysis

### Universal Cybersecurity Skill
- **Foundation**: Every cybersecurity role requires network analysis knowledge
- **Applications**: Threat hunting, incident response, SOC monitoring, penetration testing

---

## 💼 Associated Roles & Responsibilities

### 🔍 Threat Hunter
- Analyze PCAPs and live traffic for covert threats
- Detect unusual communications, C2 beaconing, custom protocols

### 🚨 SOC/Security Analyst  
- Monitor network attacks in real-time (port scans, DDoS, vulnerability scans)
- Differentiate normal traffic from suspicious activities

### 🔧 Incident Responder
- Map compromised system connections and malware communications
- Collect network forensics evidence for incident documentation

### 🎯 Penetration Tester
- Discover open ports/services, hide malicious traffic
- Perform lateral movement while evading network detection

- **Hands-on Skills**: Practical Wireshark and TCPDump usage
- **Threat Detection**: Identify network-based attacks and anomalies
- **Career Value**: Essential skill for all cybersecurity positions
- **Certification**: Course completion certificate for employers
